# 分发、版权与本地状态边界

本资料包的目标是让每个插件项目在项目内拥有 Agent 可读取的开发规范和工具，而不分发第三方 API 归档或依赖本机私有目录。

## 应分发的内容

复制到 `<plugin-project>/agent-dev/` 并建议随插件项目提交：

- `README.md` 与 `docs/` 中的规范；
- `tools/` Python 标准库工具；
- `registry/` 构件坐标、仓库和资料策略；
- 空的 `state/README.md` 或占位文件；
- 版本、变更说明和必要的示例记录模板。

这些内容应只引用相对路径和公开坐标，不包含维护者的盘符、用户名、缓存绝对路径或本机服务端位置。

## 不应分发或提交的内容

| 内容 | 原因 | 位置 |
| --- | --- | --- |
| Spigot/Paper/PluginBase/第三方的 sources/Javadoc 归档 | 体积、许可证、版本漂移 | `agent-dev/state/downloads/` |
| 已解包源码/Javadoc | 同上，且可由归档重建 | `agent-dev/state/evidence/` |
| 全文索引和临时查询结果 | 可重建、可能随工具版本变化 | `agent-dev/state/indexes/`、`records/` |
| Gradle 缓存 | 环境私有、体积大 | Gradle 用户目录，不复制 |
| 服务端运行目录、世界数据、日志、数据库 | 项目外运行数据或敏感信息 | 服务端环境，不进入资料包 |
| 密码、令牌、私有仓库凭据和真实生产连接串 | 安全敏感 | 仅安全配置渠道 |

项目根 `.gitignore` 至少应包含：

```gitignore
agent-dev/state/
```

若团队决定提交某个证据结论，应只提交精简的 Markdown 记录、坐标和哈希，不提交整份第三方归档。

## 缓存优先与联网回退

工具按以下顺序寻找资料：

1. 项目 `agent-dev/state/` 中版本和哈希匹配的现有资料；
2. 用户显式提供的 Gradle 用户目录；
3. `GRADLE_USER_HOME`；
4. 运行环境默认 Gradle 用户目录；
5. 注册表指定的公开 Maven 仓库。

工具不得把某台开发机的缓存路径写进文档、构建脚本或项目源码。联网下载前应输出将访问的 URL、目标坐标和落盘位置；下载后记录哈希。

## 未来 Skill 的边界

未来 Skill 作为简要入口和流程引导安装。为避免受保护目录需要日常修改：

- Skill 不存放本地资料、索引或任务记录；
- Skill 引导 Agent 进入当前项目 `agent-dev/`；
- 日常同步、查询和验证均写入 `agent-dev/state/`；
- 文档/工具升级通过更新普通 `agent-dev/` 目录完成；
- Skill 仅在工作流或入口协议变化时升级。

在 Skill 实现前，当前文档本身已可作为项目内入口使用。

## 许可证与来源尊重

- 获取、使用和再分发每个第三方归档时遵循其许可证、仓库条款和上游要求；
- 资料工具应只下载用户环境中为本项目开发所需的构件，不批量镜像无关版本；
- 文档记录来源 URL、坐标和哈希，保留归属和可追溯性；
- 不将上游 Javadoc/源码内容大段复制进本资料包；只记录为本次结论必要的签名与简短摘要。
