# 依赖使用笔记

`agent-dev/state/notes/` 用于保存当前插件项目在开发过程中积累的依赖使用习惯和已验证边界。它是本机持久工作笔记：不提交、不进入插件 JAR，也不替代正式项目文档、提交说明或版本证据记录。

## 何时读取与更新

- 每次开始涉及已有依赖、PluginBase 模块、服务端 API 或 Shadow 重定位的任务时，先读取相关笔记。
- 首次确认会影响后续实现选择的使用习惯后，创建或更新对应笔记。
- 修改依赖版本、移除依赖、改变重定位、替换封装方式或推翻旧结论时，更新或删除过期笔记。
- 不将“尚未证实”“可能存在”“从其它项目猜到”的内容写入笔记。

## 文件组织

使用稳定、便于定位的 Markdown 文件名：

```text
state/notes/
  pluginbase-library.md
  item-packet-modifier.md
  evalex-j8.md
  paper-api.md
```

一个文件只覆盖一个依赖、一个 PluginBase 模块或一个明确主题。不要创建按日期堆积的会话日志，也不要把所有库塞进单一大文件。

## 最小模板

```markdown
# <依赖或主题名称>

- 当前 GAV：`<group>:<artifact>:<version>`；或项目版本锚点：`<值>`。
- 最后确认：`<YYYY-MM-DD>`。
- 索引线索：`<类名、成员名、构件 GAV 或重定位后包名>`。

## 已验证使用习惯

- <项目中应遵循的封装、调用、线程或生命周期习惯>。

## 已验证边界

- <不能使用的 API、兼容限制、重定位/Shadow 注意事项或清理责任>。

## 变更条件

- <何种版本、依赖、构建或设计变化会使本笔记失效>。
```

## 内容边界

可记录：

- 项目实际解析构件 GAV、启用模块、重定位目标和索引线索；
- 已确认的适配层位置、初始化/重载/停用顺序、线程与生命周期约束；
- 已拒绝方案及原因；
- 用于复查的依赖索引类名、成员、构件 GAV、源码位置或 Javadoc 锚点；
- 哪些构建输入变化会使结论失效。

不得记录：

- 完整 sources/Javadoc、归档副本、反编译文本、大段工具输出或网页拷贝；
- 密码、令牌、私有仓库凭据、生产连接串、玩家数据、世界数据或服务器日志；
- 未验证的 API 猜测。

依赖索引负责从当前 Gradle 解析结果定位构件和公开签名；笔记只保存本项目反复使用时值得保留的决策与习惯。版本敏感代码仍须依据当前索引结果和必要的资料复核，不能仅凭旧笔记继续调用。
